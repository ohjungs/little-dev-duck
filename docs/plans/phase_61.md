# Phase 61 — 뉴스 데일리 브리핑 (cherrypick.today 벤치마킹)

> 상태: **진행 중** (2026-07-29 사용자 지시 — "오늘의 뉴스 top 3를 cherrypick.today처럼
> 매일 10개의 이슈만 보이도록, 저 사이트 참고해서 모든 기능들 가져올 수 있도록")
>
> 벤치마크 분석(2026-07-29 실사이트 조사): 하루 10개 이슈 카드 · 카드 = 번호(01~10) +
> 카테고리 라벨(경제/생활/사회/기업·기술/국제/종합) + 제목 + 부제 요약 + 이미지 ·
> 탐색 = 오늘/어제/지난주 + 달력 + 카테고리 필터 + 검색 · 보기 = 한 장씩/목록 전환 +
> 글자 크기 조절 + "오늘의 진행 n/10" · 부가 = 용어사전, SNS 연동, 피드백.

## 방향 — 그대로 베끼지 않고 LDD 자산으로 재해석

- **선정·요약은 이미 있는 한 벌 위에**: `topArticles`(news-top) · `clusterArticles`(news-cluster) ·
  Gemini 3줄 요약(`articles.summary`). top 3 → **top 10**으로 확장하는 것이지 새 파이프라인이 아니다.
- **카테고리는 피드 주제에서**: `feedTopics`(news-feeds)가 이미 주제를 안다. 기사별 재분류에
  LLM을 쓰지 않는다(무료 원칙 — 결정적 매핑 우선, HD-003).
- **진행 추적은 제품 정체성과 결합**: "오늘의 진행 n/10"을 오리와 연결 — 10개를 다 읽으면
  오리가 칭찬(기존 XP·duck 시그널 한 벌). cherrypick에는 없는 우리만의 차별점.
- **이미지**: articles에 이미지 컬럼이 없다. RSS enclosure/미디어 태그에서 추출을 시도하되(T4),
  없으면 **이미지 없는 카드가 기본** — 외부 og-image 크롤링은 비용·저작권 문제로 하지 않는다.

## Task

### T1 — core: 데일리 이슈 선정 (결정적, STDD)
- `dailyIssues(articles, feeds, { limit: 10 })`: 클러스터 중복 제거 + 최신·다양성(피드별 상한)
  기준 10개 선정. 각 이슈 = { rank 1~10, category, title, summary(3줄 요약 또는 snippet), link, publishedAt }.
- 카테고리 매핑: `feedTopics` → 경제/국제/기업·기술/사회/생활/종합 라벨. 미지정 피드는 종합.
- AC: 10개 미만이면 있는 만큼(부족을 숨기지 않음). 같은 클러스터에서 1개만. 테스트로 잠금.

### T2 — 뉴스 화면: 이슈 카드 리스트 (기본 보기)
- 뉴스 페이지 상단 "오늘의 브리핑" 섹션: 번호 + 카테고리 라벨 + 제목 + 요약 + 출처 링크 카드 10장.
- 읽음 추적: 카드 클릭(원문 열기) 시 `ldd:briefing-read:<날짜>` localStorage(관례: recentList/localRing
  재사용 검토) — "오늘의 진행 n/10" 표시.
- 10/10 달성 시 오리 칭찬 한 줄 + XP 소액(기존 `award_xp` 한 벌, 하루 1회).
- AC: 기사 0건이어도 화면이 깨지지 않고 "아직 모은 기사가 없어요" 안내.

### T3 — 탐색: 날짜·카테고리
- 오늘/어제/지난주 탭 + 날짜 선택(달력 input). 과거 날짜는 그날 수집분 기준 재선정.
- 카테고리 필터(전체/경제/국제/기업·기술/사회/생활/종합).
- AC: 과거 날짜에 기사가 없으면 빈 상태 안내. 날짜 경계는 KST(core date-util 한 벌).

### T4 — 보기 옵션·부가 (후순위)
- 한 장씩 보기(카드 스와이프/이전·다음) ↔ 목록 전환. 글자 크기 조절(기본/크게 — localStorage pref 관례).
- RSS 이미지 추출(enclosure·media:content — parseRssItems 확장, 없으면 생략).
- 용어사전·SNS 연동은 DEFER — 개인 워크스페이스에 맞지 않거나(SNS) 콘텐츠 제작이 필요(용어사전).

## 의존 계약
- DB 변경 없음(T4 이미지 추출도 컬럼 추가 시 별도 게이트). articles·feeds 기존 스키마 그대로.
- core 신규: `dailyIssues` + 카테고리 매핑(뉴스 도메인 파일에 추가, 역방향 import 없음).
- 슬라이스 순서: T1 → T2 → T3 → T4.
