# Phase 45 — 오리를 제미나이로 (1-3 · 2-5)

> 상태: **draft(예약·미착수)**
>
> 착수 전 stale 가드:
> ① 오리 자율 발화가 아직 규칙+템플릿인가(LLM 미사용)
> ② Gemini 호출 라우트가 아직 7곳이고 전부 공용 `allowRequest`를 쓰는가
> ③ `AiWriteAssistant`가 아직 158줄이고 액션 목록이 그대로인가

## 왜 이 일인가 — 이전 판단을 뒤집는 요청이다

1차 피드백 1-3을 처리할 때 **의도적으로 LLM을 쓰지 않았다.** 기록은 이렇다:

> "Phase 30 T1. **LLM을 쓰지 않았다** — 조건이 전부 결정적이라 규칙으로 고르고 문장은 템플릿."

그 판단은 **HD-003(결정적 작업은 코드로)** 원칙에 따른 것이고, 그 자체로 옳았다.
**그런데 사용자가 원한 것은 결정적 정확성이 아니라 다양성이었다.**

> "오리가 자율적으로 말을 하는게, **제미나이 기반으로 생각해서** 오늘은 비가오네요 .. 등등
> 여러가지로 **재밌는 농담**을 한다던가 바꿔주고"

**템플릿은 원리적으로 "재밌는 농담"을 못 한다** — 문장 수가 유한하고 며칠이면 다 본다.
이건 LLM이 실제로 더 나은 드문 경우다. **판단을 뒤집고, 뒤집은 근거를 기록한다.**

---

## ⚠ 먼저 정직하게 — "오늘은 비가오네요"는 제미나이가 할 수 없다

**[확인됨] LLM은 오늘 날씨를 모른다.** 학습 데이터에 없고 실시간 조회도 못 한다.
제미나이에게 "오늘 날씨 얘기해줘"라고 하면 **그럴듯한 거짓말을 만든다** —
비가 안 오는 날 "비가 오네요"라고 말하는 오리가 된다.

이 저장소는 **없는 데이터를 지어내지 않는다**는 원칙을 이미 세웠다
(1차 피드백 4-5: "조회수는 우리에게 없는 데이터라 지어내지 않았다").

### 선택지 — 사용자 결정이 필요하다

| | 방법 | 비용 | 결과 |
|---|---|---|---|
| **(가)** | **날씨 API 연동** (Open-Meteo: 무료·API 키 불필요) | 신규 외부 호출 1개 · 위치 정보 필요 | "오늘은 비가오네요"가 **사실이 된다** |
| (나) | 날씨는 빼고 농담·격려만 LLM으로 | 0 | 요청의 예시 하나를 못 함 |
| (다) | 날씨를 언급하되 "~라던데요" 식으로 회피 | 0 | **거짓말이다.** 채택하지 않는다 |

**권고: (가).** Open-Meteo는 무료 원칙에 맞고 키가 필요 없다.
위치는 **도시 단위 고정값(서울)으로 시작**한다 — 브라우저 위치 권한을 요청하면
알림 권한과 같은 문제(거부되면 되돌릴 수 없다)가 생긴다.
**착수 전 확인한다.** 답이 없으면 (나)로 진행하고 그 사실을 적는다.

## T1 — 오리 자율 발화를 LLM으로 (1-3)

### 만들 것

- **기존 규칙 엔진을 버리지 않는다.** 규칙이 **무엇에 대해 말할지**를 정하고(결정적),
  LLM이 **그것을 어떻게 말할지**를 정한다(창의적). HD-003의 정확한 적용이다 —
  "LLM은 판단·우선순위·재작성에만 쓴다."
  - 규칙: "미완료 할 일 3건 · 3일 연속 습관 성공 · 오후 4시 · 비" → **맥락(사실)**
  - LLM: 그 사실로 한 문장 만들기 → **표현**
  - **사실은 우리가 준 것만 쓰라고 못박는다.** 안 그러면 없는 할 일을 언급한다.
- **무료 쿼터를 지킨다 — 이게 이 Task의 가장 큰 제약이다.**
  자율 발화는 **주기적으로 일어난다**(사용자가 부르지 않아도). 순진하게 만들면
  대시보드를 열어 둔 채로 쿼터를 태운다.
  - **공용 `allowRequest`를 쓴다**(`@ldd/api`). 자체 `Map` 재구현은
    **CLAUDE.md 3-5절 최고 심각도 인벤토리 위반** — [Phase 36](phase_36.md)에서 데인 그것.
  - **생성한 문장을 캐시한다.** 맥락이 같으면 다시 부르지 않는다.
    맥락 해시를 키로 쓴다(결정적 — 코드로).
  - **하루 상한**을 둔다. 넘으면 **기존 템플릿으로 조용히 떨어진다** —
    쿼터가 없다고 오리가 입을 닫으면 기능이 사라진 것처럼 보인다.
    **저하 모드가 곧 기존 동작**이라 안전하다.
- **프롬프트 인젝션 방어를 붙인다.** 맥락에 **사용자 데이터**(할 일 제목 · 일정 제목 · 메모)가
  들어가고, 일정 제목은 **구글 캘린더 초대로 남이 만든 텍스트**일 수 있다.
  [Phase 32](phase_32.md)가 만든 core `untrustedTextRule`을 **그대로 쓴다** —
  두 벌로 두면 한쪽만 고쳐진다. Phase 32가 진입점 개수를 테스트로 못박아 뒀으므로
  **새 진입점을 추가하면 그 테스트가 먼저 운다**(설계대로 동작하는 것이다).
- **표정을 문장과 맞춘다** — Phase 30 T1이 이미 하는 것이다. LLM이 문장과 함께
  표정 키를 고르게 하되 **허용 목록 안에서만**(모르는 값이 오면 기본 표정).

## T2 — AI 작문 도우미를 오리가 (2-5)

### ⚠ 이 항목은 1차 피드백과 **원문이 글자 단위로 같다**

1차 2-5와 2차 2-5가 **완전히 동일한 문장**이다. 1차에서 `0ddcf12`로
"오리 표시 + 액션별 상태 문구 + 액션 3종 추가"를 하고 ✅로 적었다.

**같은 요청이 그대로 다시 올라온 것은 1차 처리가 사용자 기대에 못 미쳤다는 신호다.**
그래서 이 Task는 **"무엇이 부족했나"를 먼저 확인하고 시작한다.**

### 원문이 명시한 것 — 하나씩 대조한다

> "AI 작문 도우미라고 있는데 이 기능을 **오리가 돌아다니면서** 도울수있게
> **오리 이미지** (오리가 생각중 .. 오리가 생성중 ..) 등으로 해서 오리를 이용한
> **템플릿 이용**이라던지 **요약**, **작문**, **다른페이지 가져오기** 등
> 여러가지 LLM 기능을 여기서도 사용가능했으면 좋겠어

| 요구 | [확인 필요] 1차에서 됐나 | 판정 방법 |
|---|---|---|
| 오리가 **돌아다니면서** | **[추정] 안 됐다** | 고정 위치 표시인지 확인. "돌아다닌다"는 움직임 요구다 |
| 오리 **이미지** + 상태 문구 | 됐다고 기록됨 | 실제로 오리 그림이 뜨는지 확인 |
| **템플릿 이용** | ? | 액션 목록에 있는지 |
| **요약** | ? | 같음 |
| **작문** | 원래 있음 | |
| **다른 페이지 가져오기** | ? | RAG로 다른 페이지를 참조하는 액션 |

**"오리가 돌아다니면서"가 1차에서 빠진 부분이라고 본다.**
[`WalkerScene`](../../apps/web/src/components/WalkerScene.tsx)·`WalkingModeToggle`이
이미 오리를 화면에서 걷게 하는 구조를 갖고 있다 — **그걸 재사용한다.**

### 만들 것

- **오리가 편집 화면 안을 걸어다니며** 도움을 제안한다. 클릭하면 액션 메뉴.
  - **글쓰기를 방해하면 안 된다.** `pointer-events` 관리 + 텍스트 위를 가리지 않게.
  - **`prefers-reduced-motion`을 존중한다.** 모션 축소 설정이면 움직이지 않는다.
    CLAUDE.md 3-1: 접근성은 깎지 않는다.
  - 끌 수 있어야 한다(설정 → [Phase 49](phase_49.md)).
- **액션 4종을 채운다**: 템플릿 적용 · 요약 · 이어 쓰기 · **다른 페이지 가져오기**(RAG).
  - "다른 페이지 가져오기"는 **RAG가 이미 있다** —
    저장할 때마다 `pageEmbedText`로 재색인한다([`PageEditor.tsx:317`](../../apps/web/src/components/PageEditor.tsx#L317)).
    **검색 경로를 재구현하지 않는다.**
  - **참조한 페이지를 밝힌다.** 어디서 가져온 문장인지 모르면 사용자가 검증할 수 없다.
- **상태 문구를 실제 단계와 맞춘다**("오리가 생각중" → "오리가 생성중" → 완료).
  가짜 단계를 보여주면 **오피스에서 지적받은 "일하는 척"과 같은 부류**가 된다(1차 5-7).
- **인젝션 방어**: 본문이 **가져온 템플릿**(Phase 30 T3)에서 왔을 수 있다 —
  Phase 32가 이 경로를 이미 지적했다. `untrustedTextRule`을 쓴다.

## 의존 계약

- **신규 의존성 0개.** Gemini 호출 경로·RAG·걷는 오리가 전부 있다.
- **신규 외부 호출 0~1개** — T1의 (가) 선택 시 Open-Meteo. **사용자 결정 대기.**
- **마이그레이션 0개.** 캐시는 인스턴스 메모리(한계를 주석에 적는다 — `PENDING.md` 6번과 같은 부류).
- **core 계약 먼저**: 프롬프트 조립은 **core에 둔다.** [Phase 32](phase_32.md)가
  "api에서 문자열을 이어 붙이면 테스트가 닿지 않고, 그래서 방어가 빠진 걸 아무도 못 봤다"를
  겪었다. **같은 실수를 반복하지 않는다.**

## 하지 않을 것

- **날씨를 지어내는 것.** (다)는 채택하지 않는다.
- **기존 템플릿 엔진 삭제.** 쿼터 소진 시 저하 모드로 쓴다.
- **응답을 다시 모델로 검사하는 것.** 무료 쿼터가 배로 나간다([Phase 32](phase_32.md)와 같은 판단).
- **자율 발화 주기를 짧게.** 쿼터를 태우고 사용자를 방해한다.
- **`untrustedTextRule`을 다시 쓰는 것.** 인벤토리 위반.
