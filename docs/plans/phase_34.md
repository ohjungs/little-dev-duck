## 왜 이 일인가

사용자 요구 원문(2026-07-26 피드백 2-6)의 **마지막 남은 조각**이다.

> "페이지 기능안에 그안에서 엑셀 + 파워포인트 + 워드 기능도 구현했으면 좋겠어"

- 워드 → [Phase 30 T4-a](phase_30.md) 완료(인쇄·PDF 지면 규칙).
- 엑셀 → [Phase 33](phase_33.md) 완료(표 열 집계).
- **파워포인트 → 이 Phase.** Phase 30이 "가장 멀다"며 별도 Phase로 미뤄 둔 것이다.

이걸 끝내면 **사용자가 말로 요구한 30여 항목이 전부 처리된다**(확인 불가 2건 제외).

## 확인된 사실 (2026-07-26 코드로 확인, 추측 아님)

| 항목 | 상태 | 근거 |
|---|---|---|
| 슬라이드/발표 기능 | **없다** | `pageTemplates.ts` 12종에 없고 관련 컴포넌트 0건 |
| `pptxgenjs`·`reveal.js` 등 | **미설치** | Phase 30 확인 사항, 이후 변동 없음 |
| 에디터 | BlockNote(블록 흐름) | 고정 캔버스가 아니다 — **이게 핵심 거리다** |
| 인쇄 지면 규칙 | 있다 | `globals.css` `@media print` — `@page` 여백·`break-inside: avoid` |
| 전체화면 API | 브라우저 네이티브 | 의존성 없이 `requestFullscreen()` |

## 설계 판단 (착수 전 확정 — 여기가 이 Phase의 전부다)

**의존성을 들이지 않는다.** `pptxgenjs`(pptx 파일 생성)나 `reveal.js`(발표 프레임워크)를 넣으면
번들이 커지고, 둘 다 **우리 블록 모델과 별도의 문서 모델**을 요구한다.

**고정 캔버스 편집기를 만들지 않는다.** 자유 배치 슬라이드(드래그로 텍스트 상자 놓기)는
BlockNote 위에 얹을 수 없고 사실상 새 에디터다. 이 제품 규모에 과하다.

**대신: 페이지를 슬라이드로 "보여준다"(발표 모드).**

- 페이지 본문의 **1단계 제목(h1)을 슬라이드 경계**로 삼는다. 사용자가 이미 쓰는 문법이라
  새로 배울 게 없고, 문서와 슬라이드가 **한 원본**이라 어긋나지 않는다.
- 발표 모드 = 전체화면 + 한 번에 한 구간 + 좌우 키 이동. 편집이 아니라 **표시**다.
- 인쇄하면 슬라이드 한 장이 종이 한 장이 된다(T4-a의 `@page` 규칙 재사용).

이게 "파워포인트"의 요구를 만족하는지: **발표한다는 목적**은 만족한다. 애니메이션·테마·
자유 배치는 못 한다. **착수 전 이 해석을 사용자에게 확인한다**(엑셀에서 겪은 것과 같은 갈림길).

## Task (안)

- **T1 — core: 본문 → 슬라이드 분할(순수).**
  - `splitIntoSlides(blocks)` — h1 기준 구간 나누기. 제목 앞 서문은 첫 장(표지).
  - 수용 기준: h1이 없으면 전체가 한 장 · 빈 페이지는 빈 배열 · 중첩 블록 보존 ·
    슬라이드 수 상한(예: 200)으로 폭주 방지.
- **T2 — 발표 모드 화면.**
  - 페이지 도구 모음에 "발표" 버튼. 전체화면 + 좌우/스페이스 이동 + Esc 종료.
  - **접근성**: 키보드만으로 전부 조작 · 현재 장/전체 장 수를 스크린리더에 알림 ·
    움직임 줄이기 설정이면 전환 효과 없음.
  - **되돌릴 수 없는 일이 아니다** — 읽기 전용이라 안전하다.
- **T3 — 인쇄에서 한 장씩.**
  - 발표 모드일 때만 슬라이드 경계에 `break-after: page`. T4-a 규칙과 충돌 없는지 확인.

## 의존 계약

- core: `splitIntoSlides` 순수함수 + 슬라이드 상한 상수.
- **DB 마이그레이션 없음 · 신규 의존성 없음.** 기존 `pages.content`를 다르게 볼 뿐이다.
- UI는 페이지 화면(`PageEditor`/도구 모음)과 새 발표 컴포넌트만.

## 하지 않을 것

- `.pptx` 파일 내보내기(의존성 필요, 그리고 우리 모델과 매핑이 손실적이다).
- 고정 캔버스 자유 배치 · 슬라이드 전환 애니메이션 · 발표자 노트 화면(2차).
- 슬라이드 전용 저장 모델. **한 원본**이 이 설계의 핵심이라 이걸 깨면 이 Phase의 근거가 사라진다.
