## Task

### T1 — "지원 현황" 데이터베이스 템플릿 (완료)
- PAGE_TEMPLATES에 job-tracker 추가: 단계(관심→서류 준비→지원 완료→서류 합격→면접→
  최종 합격/불합격) select + 직무·마감일·공고 링크. 표 + 단계별 칸반 보드.
- 기존 잠금 테스트(스키마 검증·보드 그룹 속성 실재·h1 유일성) 통과로 계약 보장.
- AC: 새 페이지 → 템플릿에서 "지원 현황" 선택 → 표/보드 즉시 사용 가능. [완료]

### T2 — 오리가 지원 현황을 아는가 (완료)
- 확인 결과 [확인됨]: **안 들어갔다** — DatabaseView는 재인덱싱을 안 불렀고 속성은
  plain_text에도 없었다(본문 없는 행은 오리 지식에 부재).
- 배선 완료: core `dbRowEmbedText`(테스트 3건 — select는 옵션 이름으로, 모르는 값은
  건너뜀) + DatabaseView 행 생성·제목·속성 변경 성공 시 reindexSource(page) 호출.

### T3 — 면접 일정 → 캘린더 연계 (후순위, 확인 먼저)
- 지원 현황의 마감일/면접일을 캘린더 위젯 D-day로 잇는 것 — DB 행과 calendar_events는
  별개 저장소라 자동 동기화는 새 설계다. **오리 커맨드("내일 3시 면접 잡아줘")가 이미
  일정을 만들 수 있으므로** 그 안내 문구로 충분한지 먼저 판단. 과잉이면 폐기.
