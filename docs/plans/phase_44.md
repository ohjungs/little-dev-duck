> ## T1 완료 — `[추정]`이 사실로 확정됐다
> 계획은 "**사용자는 이 소리를 아예 못 들었을 가능성이 높다**"고 `[추정]`으로 적었다.
> **코드로 확정된다**: 전에는 완료 시점에 `new AudioContext()`를 만들었는데, 브라우저는
> **사용자 제스처 없이 만든 컨텍스트를 `suspended`로 시작**시킨다. 타이머 만료는 제스처가
> 아니다 — 즉 **그 소리는 한 번도 난 적이 없다.** 게다가 완료할 때마다 새 컨텍스트를 만들고
> 닫지 않아 누수까지 있었다.
> - **컨텍스트를 시작 버튼(진짜 제스처) 때 한 번 만들어 재사용**한다. `suspended`와 누수가
>   함께 사라진다 — 새 파일도 새 의존성도 필요 없다(ponytail).
> - **알림은 새로 만들지 않았다.** `lib/notify.ts`의 `notifyDuck`이 **권한·방해금지 시간대·
>   하루 총량**을 이미 전부 판정한다. 계획이 "재구현 금지"로 못박은 그대로 배선만 했다.
> - **권한은 시작 버튼에서 묻는다.** 페이지 로드 시 물으면 사용자는 반사적으로 거부하고,
>   한 번 거부되면 브라우저 설정을 직접 열기 전에는 되돌릴 수 없다.
> - **소리는 합성음으로 남겼다(정직하게).** 계획은 실제 음원 파일을 쓰라고 했지만
>   `public/sounds/`의 CC0 자산 7개는 문·발소리·타이핑이라 알람으로 쓸 것이 없고, 외부에서
>   새 자산을 내려받는 것은 라이선스 확인이 필요해 범위 밖으로 뒀다. 대신 **단발 삐 소리를
>   두 음 차임(삼각파)으로** 바꿨다 — 이 저장소가 "사인파를 이상한 사운드로 지적받아 걷어낸"
>   전례가 있어 알람처럼 들리는 형태로 다듬었다. **실제 음원 교체는 자산이 생기면 한 줄이다.**
> - **음소거 스위치**를 함께 뒀다(요청엔 없지만 소리는 늘 끌 수 있어야 한다 — 오피스 사운드 관례).
> - 검증: turbo test·lint·build **18/18 GREEN**. **소리·알림은 실제로 못 들어 봤다** —
>   대시보드 위젯이라 로그인이 필요하고, 알림 권한은 사람이 눌러야 한다.>

> ## T3 절반 완료 — 마이그레이션 없이 되는 쪽을 먼저 했다
> 요청("메모가 잘 안보여서 색깔 지정")은 **두 가지**다: ① 색이 흐려서 안 보인다 ② 색을 고를 수 없다.

> - **ΔE 계산을 core로 올렸다**(`color-distance.ts`, 테스트 8건). 잔디 검사에 복붙하면 두 벌이 되고

>   갈색과 주황이 거의 같았다).
> - **검사가 헛돌 뻔한 것을 잡았다**: 정규식을 템플릿 리터럴에 넣으면서 `\s`가 `s`로 죽어
>   **아무것도 매칭하지 않았다.** `String.raw`로 고쳤다 — 통과했다고 검사가 사는 게 아니다.

## 왜 이 일인가

**대시보드는 이 제품의 첫 화면이고, 요청 4건이 전부 "내가 통제할 수 없다"는 불만이다.**
카드 위치를 못 옮기고(1-5), 메모 색을 못 고르고(1-6), 캘린더 크기를 못 바꾸고(1-7),
타이머가 끝난 걸 모른다(1-4).

**공통 성질: 판정 로직은 이미 있고 입력 수단이 없다.**
`moveWidget`(순서) · `MEMO_COLORS`(색) · `todayIso`(오늘) · `playCompletionSound`(소리)가
전부 존재한다. **이 Phase는 대체로 "이미 있는 것에 손잡이를 붙이는" 일이다** —
재구현하면 인벤토리 위반이다.

## T1 — 뽀모도로 완료 알람음 + 팝업 (1-4)

### 지금 상태 — 소리는 있는데 알람이 아니다

[`PomodoroWidget.tsx:27`](../../apps/web/src/components/PomodoroWidget.tsx#L27)
`playCompletionSound()`가 **사인파 523Hz(C5) 0.5초 한 번**이다.
팝업은 없다 — `Notification` API를 쓰지 않는다.
[`setCelebrate(true)`](../../apps/web/src/components/PomodoroWidget.tsx#L204)는 위젯 안 문구일 뿐이라
**다른 탭을 보고 있으면 아무것도 모른다.**

### [추정] 사용자는 이 소리를 아예 못 들었을 가능성이 높다 — 착수 전 확인할 것

브라우저는 **사용자 제스처 없이 만든 `AudioContext`를 `suspended` 상태로 시작**시킨다.
타이머 완료는 제스처가 아니다. 게다가 **매 완료마다 새 컨텍스트를 만들고 닫지 않는다**(누수).

확인 방법: 짧은 타이머를 끝까지 두고 완료 시점에 콘솔에서 `AudioContext.state`를 본다.
`"suspended"`면 소리가 **한 번도 난 적이 없다**.

### 만들 것

- **실제 음원 파일로 바꾼다.** `public/sounds/`에 이미 Kenney CC0 자산 7개가 있고
  라이선스 파일(`LICENSE.txt`)까지 갖춰져 있다 — **같은 출처에서 알람음을 받아 쓴다.**
  이 저장소는 **오피스에서 사인파 BGM을 "이상한 사운드"로 지적받아 걷어낸 전례**가 있다
  (1차 피드백 5-1). **같은 부류를 두 번 내지 않는다.**
- **`AudioContext`를 재사용하고 첫 제스처(시작 버튼) 때 만든다.** 누수와 `suspended`를 함께 해결한다.
  `<audio>` 요소를 쓰면 더 단순하다 — **ponytail 사다리: 플랫폼 네이티브가 먼저다.**
- **브라우저 알림(팝업)을 띄운다.** `Notification` API.
  - **권한을 마음대로 요청하지 않는다.** 페이지 로드 시 권한 팝업을 띄우면 사용자는 거부하고
    그러면 되돌릴 수 없다. **타이머를 처음 시작할 때** 또는 설정에서 요청한다.
  - **거부됐을 때 대비**: 탭 제목을 바꾸거나(`document.title`) 위젯을 강조한다.
    권한이 없다고 아무 알림도 없으면 안 된다.
  - **방해 금지 시간대를 존중한다** — [`QuietHoursSetting`](../../apps/web/src/components/QuietHoursSetting.tsx)이
    이미 있다. **재구현 금지.**
  - **집중 모드 플래그도 존중한다** — [`FOCUS_MODE_KEY`](../../apps/web/src/components/PomodoroWidget.tsx#L42)가
    이미 있고 `DuckWidget`이 그걸로 알림을 억제한다. 완료 알림은 집중이 끝난 시점이라
    억제 대상이 아니지만, **그 판정을 새로 쓰지 말고 기존 신호를 쓴다.**
- 음소거 설정을 준다(요청에 없지만 소리는 항상 끌 수 있어야 한다 — 오피스 사운드에도 있다).

## T2 — 카드를 마우스로 잡아서 위치 변경 (1-5)

### 만들 것

- **순서 판정은 core `moveWidget`을 그대로 쓴다.** 드래그는 **입력 수단만 추가**하는 일이다.
  드롭 위치에서 "몇 칸 위/아래로"를 계산해 기존 함수를 부른다.
  **자체 순서 로직을 쓰면 두 벌이 되고 버튼과 드래그 결과가 갈라진다.**
- **관리자 패널이 아니라 대시보드에서 직접 끈다.** 요청이 "기존에 카드 형태의 대쉬보드를
  마우스로 잡아서"다 — 설정 화면이 아니라 **대시보드 자체에서**다.
  [`DashboardGrid`](../../apps/web/src/components/DashboardGrid.tsx)에 붙인다.
- **키보드로도 옮길 수 있어야 한다.** 드래그만 만들면 **접근성 회귀**다.
  기존 위/아래 버튼을 **지우지 않는다** — 그게 키보드 경로다.
  CLAUDE.md 3-1: "검증, 에러 처리, 보안, 접근성은 절대 깎지 않는다."
- **저장 실패를 조용히 넘기지 않는다.** 배치 저장은 **마이그레이션 미적용이라 지금 실패한다.**
  [Phase 37](../Status.md)이 만든 `pendingMigrationMessage`가 **이미 이 자리에 한국어 안내를 띄운다** —
  그 배선을 유지한다. 드래그 후 화면이 되돌아가면서 안내가 뜨는 것이 지금의 정상 동작이다.
- **[확인 필요] 신규 의존성.** HTML5 drag-and-drop API로 되면 의존성 0개다.
  `@dnd-kit` 같은 라이브러리는 터치·키보드·스크린리더를 잘 처리하지만 의존성이 늘고,
  **ponytail 사다리 4단계(플랫폼 네이티브)를 먼저 시도해야 한다.**
  그리드(2~3열)에서 HTML5 DnD가 충분한지 실측하고 결정한다.

## T3 — 메모 색상 팔레트 (1-6)

### 지금 상태 — 요청이 두 가지다

[`MemoWidget.tsx:326`](../../apps/web/src/components/MemoWidget.tsx#L326)이
`MEMO_COLORS[index % MEMO_COLORS.length]`다:

1. **색을 사용자가 고를 수 없다** — 목록 순서로 자동 배정된다.
   메모를 하나 지우면 **나머지 전부의 색이 밀린다**(index가 바뀌므로).
2. **색이 [`bg-yellow-50` 등 `-50` 단계](../../apps/web/src/components/MemoWidget.tsx#L35)라
   흰 카드 배경에서 거의 구분되지 않는다** — 사용자가 말한 "메모가 잘 안보여서".

### 만들 것

- **색을 메모에 저장한다.** `memos` 테이블에 `color` 컬럼 추가 → **마이그레이션 1건.**
  - **down 스크립트를 동반한다** (CLAUDE.md 5절).
  - **미적용 상태에서 안전하게 떨어져야 한다** — 이 저장소가 **"미적용 컬럼을 payload에
    무조건 실어 테이블 쓰기가 통째로 죽은" 사고**를 겪었다([Phase 37](../Status.md)).
    **값이 있을 때만 키를 넣는다.** 컬럼이 없으면 지금처럼 index 기반으로 떨어진다.
  - **마이그레이션이 이미 4건 밀려 있다.** 다섯 번째를 쌓는 것이므로
    **[Phase 49](phase_49.md)의 일괄 적용에 합류시킨다** — 순서상 이 Phase가 먼저지만
    적용은 함께 한다. 그 사실을 완료 보고에 적는다.
- **채도를 올린다.** `-50` → `-100`/`-200` 수준 + 테두리를 색과 맞춘다.
  **대비를 숫자로 잠근다** — [Phase 42 T6](phase_42.md)의 잔디와 같은 방식.
  눈으로 고르면 또 지적받는다.
- **팔레트 UI**: 메모 카드 위 작은 색 점 6~8개. 클릭하면 즉시 적용·저장.
  `aria-label`로 색 이름을 준다(색만으로 구분하게 두면 접근성 위반).
- **다크 모드에서도 구분돼야 한다.** 지금 `dark:bg-*-950/30`은 거의 검정이라 서로 구분이 안 된다.

## T4 — 캘린더 (1-7)

### 원문 — 요구가 4개다

> "캘린더가 너무 뭉개지고, 아무것도 안골르면 당장 오늘로하고, 이거 지난거는 볼건지안볼건지도
> 중요하고 사이징도 변경가능하게 해줘"

| # | 요구 | 지금 상태 |
|---|---|---|
| a | 뭉개짐 | 셀이 좁다 — 위젯이 그리드 1칸(md:col-span 없음)이라 월 7열이 눌린다 |
| b | 아무것도 안 고르면 오늘 | [`selectedDate`가 `null`로 시작](../../apps/web/src/components/CalendarWidget.tsx#L114)하고 `null`이면 [전체 일정을 보여준다](../../apps/web/src/components/CalendarWidget.tsx#L209) |
| c | 지난 것 볼지 말지 | **없다** — 지난 일정은 [흐리게 표시만](../../apps/web/src/components/CalendarWidget.tsx#L54) 된다 |
| d | 사이징 변경 | **없다** |

### 만들 것

- **(b) 기본 선택을 오늘로.** `useState(() => todayIso())`.
  [`todayIso`](../../apps/web/src/lib/today.ts)가 이미 있다 — 재구현 금지.
  **날짜 계산을 새로 쓰지 않는다**: 이 저장소는 하루 밀림을 여러 번 겪어
  eslint 규칙(`toISOString().slice()` 금지)까지 만들었다.
- **(c) 지난 일정 보기 토글.** 기본값은 **숨김**(요청의 "볼건지 안볼건지"에서
  묻는다는 것 자체가 지금 보이는 게 방해된다는 뜻). 토글 상태를 기억한다.
- **(d) 크기 조절.** 3단계(작게·보통·크게)로 준다. **자유 리사이즈는 하지 않는다** —
  그리드 레이아웃 안에서 임의 크기는 다른 카드를 밀어내고, 그 상태를 저장·복원하는 비용이 크다.
  3단계는 `md:col-span` / 셀 크기 조합으로 표현되고 **저장은 T3와 같은 설정 경로**를 쓴다.
- **(a) 뭉개짐은 (d)가 대체로 해결한다.** 다만 **작게 상태에서도 읽을 수 있어야** 한다 —
  최소 셀 크기를 정하고, 그 아래로는 월 그리드 대신 **목록 뷰로 전환**한다.
  7열을 억지로 쥐어짜는 것이 "뭉개짐"의 직접 원인이다.
