> 계정 삭제 + 전체 데이터 파기 (Supabase cascade 설계) — `FEATURES.md:192` (Phase 13 배정)
> "공개 배포 전 개인정보·법적 요구사항"

그리고 **코드가 스스로 미완이라고 적어 뒀다**:

> `packages/api/src/account.ts:9`
> "계정(auth.users) 자체 삭제는 Edge Function(service_role)이 필요해 **2단계로 이월** — profiles는 남는다."

지금 "위험 구역"은 **내 콘텐츠만** 지운다. 화면도 그렇게 말한다("로그인 계정 자체는 유지돼
다시 사용할 수 있어요") — **거짓말은 아니다.** 다만 이 앱은 Google·GitHub 로그인으로 공개 배포돼
있고, 가입한 사람이 **자기 계정과 이메일을 지울 방법이 없다.**

## 설계 판단 (여기가 이 Phase의 핵심 — 위험한 키를 다루기 때문이다)

`service_role` 키는 **RLS를 통째로 우회한다.** 잘못 배선하면 지금 있는 구멍보다 나쁘다.
그래서 다음을 계약으로 못박는다.

1. **키는 서버 라우트 안에서만 읽는다.** `NEXT_PUBLIC_` 접두 금지, 클라이언트 번들 유입 금지
   (테스트로 잠근다 — 빌드 산출물에 키 이름이 있으면 실패).
2. **라우트는 "지금 로그인한 사람 자신"만 지운다.** 요청 본문의 user id를 **절대 믿지 않는다** —
   세션에서 꺼낸 `auth.getUser()` 결과만 쓴다(Phase 29 `restoreTodo`가 세운 계약과 같다).
3. **키가 없으면 기능이 꺼진 것처럼 동작한다.** 500이 아니라 "관리자가 설정하지 않았습니다"로
   명확히 답하고, 화면은 그 버튼을 아예 보여주지 않는다. **미설정이 곧 안전한 기본값**이다.
4. **콘텐츠를 먼저 지우고 계정을 마지막에 지운다.** 순서가 뒤집히면 세션이 죽어 콘텐츠 삭제가
   중간에 멈추고, 사용자는 **지워졌다고 믿는 남은 데이터**를 갖게 된다.
5. **되돌릴 수 없다.** 지금의 문구 타이핑 게이트를 그대로 쓰되 **문구를 다르게** 한다
   (콘텐츠 삭제와 계정 삭제가 같은 문구면 손이 기억한 대로 눌러 계정까지 지운다).
6. **속도 제한**을 건다. 되돌릴 수 없는 라우트라 실수·자동화 반복 호출을 막는다
   (`keepalive`가 쓰는 방식 재사용 — 새로 만들지 않는다).

## Task (안)

- **T1 — core: 삭제 절차의 순서·전제를 순수함수로.**
  - 무엇을 어떤 순서로 지울지, 어디서 멈춰야 하는지를 값으로 표현하고 테스트한다.
  - 수용 기준: 콘텐츠 → 계정 순서가 뒤집히면 실패하는 테스트가 있다.
- **T2 — 서버 라우트 `POST /api/account/delete`.**
  - 세션에서 사용자 확인 → 콘텐츠 삭제 → 계정 삭제 → 세션 종료.
  - 키 미설정이면 **503과 명확한 사유**. 요청 본문의 id는 읽지 않는다(읽으면 실패하는 테스트).
- **T3 — 화면: 위험 구역에 "계정까지 삭제" 추가.**
  - 키가 없으면 **버튼 자체를 렌더하지 않는다**(없는 기능을 보여주면 눌러 보고 실패한다).
  - 문구 타이핑 게이트 + 무엇이 사라지는지 명시(로그인 수단·이메일 포함).
- **T4 — 문서**: `.env.example`에 키 추가 + `PENDING.md`에 설정 방법.

## 의존 계약

- **DB 마이그레이션 없음.** Supabase Admin API(`auth.admin.deleteUser`)를 서버에서 호출한다.
- 신규 의존성 없음(`@supabase/supabase-js`에 이미 포함).
- **사용자 조치 1건**: Vercel에 `SUPABASE_SERVICE_ROLE_KEY` 추가. 없으면 기능이 꺼진 채로
  지금과 완전히 동일하게 동작한다.

## 하지 않을 것

- Edge Function 인프라 신설(서버 라우트로 충분하다).
- 관리자가 **남의** 계정을 지우는 기능. 요구에 없고, 잘못 만들면 피해가 크다.
- 유예 기간·복구 대기열. 되돌리기를 만들면 "파기"가 아니게 되고, 그건 이 MUST의 취지와 어긋난다.
