## ⚠ 여기 유일하게 뒤로 민 MUST가 있다 — W-002

원본은 **W-002(데스크톱 위젯 내 축약형 채팅 뷰)를 MUST**로 잡았다.
**이 배정이 그것을 SHOULD로 내렸다.** 근거를 남긴다:

- 데스크톱 위젯은 **확정 스택의 주요 표면이다**(CLAUDE.md 1절 "위젯 모드"). 판단이 맞다.
- **그런데 웹에서 메신저가 성립하기 전에 두 번째 표면을 만들면 양쪽을 두 번 고친다.**
  [Phase 50](phase_50.md)~[52](phase_52.md)가 방·메시지·카드 계약을 굳힌 **뒤에** 얹는 것이 싸다.
- **되돌릴 수 있는 결정이다** — 위젯 뷰를 나중에 얹는 것은 계약을 안 깨지만,
  계약이 흔들리는 동안 두 표면을 유지하는 것은 비싸다.

**이것이 MUST 61건 중 유일하게 P53 이후로 간 항목이다.** 나머지 60건은 P52 이전에 있다.

CLAUDE.md 3-1: **"검증, 에러 처리, 보안, 접근성은 절대 깎지 않는다."**

- **W-013 오프라인 표시**: [`OfflineIndicator`](../../apps/web/src/components/OfflineIndicator.tsx)가
  **이미 있다**(B-007 = 완료). **재구현 금지** — 메신저 전송 차단 안내만 연결한다.
- **W-011 클립보드 감지는 프라이버시 표면이다.** 항상 감시하면 안 된다 —
  **창이 활성일 때 + 사용자가 켠 경우만.** 기본은 꺼짐.

## T3 — 성능 (W 5항목)

- **W-024 가상 스크롤이 이 Task의 핵심이다.** 대화가 길어지면 DOM 노드가 수천 개가 된다.
  - **[Phase 51](phase_51.md)의 커서 페이지네이션(B-020) 위에 얹는다.**
  - **의존성 판단**: `react-window`/`virtua` 같은 라이브러리가 있지만
    **ponytail 사다리 4단계(플랫폼 네이티브)를 먼저 시도한다** —
    `content-visibility: auto`가 브라우저 네이티브로 상당 부분 해결한다. **실측하고 결정한다.**
- W-025 이미지 지연 로딩(`loading="lazy"` — 네이티브) · W-026 렌더 배칭·메모이제이션.
- **W-027 3D 오리 + 채팅 동시 성능 예산** — 이 제품에만 있는 문제다.
  `react-three-fiber` 오리와 가상 스크롤 대화가 같은 화면에 있으면 프레임이 떨어진다.
  → **예산을 숫자로 정한다**(예: 오리 렌더 상한 fps, 채팅 렌더 우선).
- **W-028 2D PNG 폴백** — 이미 그 개념이 있다(`DuckVideo`·`AnimatedDuckLogo`가 영상/PNG를 쓴다).
  **성능 미달 시 자동 전환 판정을 한 벌로 둔다.**

## T4 — 웹 표면 (W 7항목)

- W-014 PWA 설치 · W-015 서비스워커 오프라인 캐시 · W-019 딥링크 · W-020 공유 시트 ·
  W-021 홈 화면 위젯 · W-022 스와이프 제스처 · W-023 햅틱 · G-018 백그라운드 전송.
- **⚠ W-015 서비스워커는 위험하다.** 이 저장소는 **nonce 기반 CSP를 쓰고, 정적 프리렌더와
  충돌해 로그인이 완전 불능이 된 사고를 두 번 겪었다**([Phase 38](../Status.md) + 그 이전).
  서비스워커가 응답을 캐시하면 **nonce가 굳은 HTML이 재사용되어 같은 부류의 사고가 난다.**
  → **[Phase 38](../Status.md)의 `buildStaticGuard`가 이 부류를 검사한다.**
  서비스워커를 넣으면 **그 가드를 확장해야 한다.** 안 하면 세 번째로 밟는다.
- **W-022·W-023은 모바일 전용** → 실제 사용은 [Phase 60](phase_60.md)의 RN 클라이언트 이후.
  웹에서도 스와이프는 가능하지만 **마우스 사용자에게 숨은 기능이 된다** — 대체 경로 필수.

## 의존 계약

- **신규 의존성 0~1개.** 가상 스크롤은 `content-visibility`를 먼저 시도.
- **마이그레이션 0건.**
- **[Phase 38 가드 확장 필수]** 서비스워커를 넣으면 CSP·정적 프리렌더 가드를 확장한다.
- **core 승격 2건**: 시간대 처리(X-013) · 모션 축소 판정(X-006). **둘 다 지금 두 벌 이상이다.**

## 하지 않을 것

- **`OfflineIndicator`·`ShortcutsHelp` 재구현.** 있다. 인벤토리 위반.
- **가드 확장 없이 서비스워커 도입.** CSP 사고를 세 번째로 밟는다.
- **대체 텍스트 강제.** 사진을 안 보내게 된다.
- **클립보드 상시 감시.** 프라이버시 표면이다.
- **i18n 구조 없이 언어 토글.** 껍데기다.
- **모션 축소 판정을 세 곳에서 따로.** 한 벌로.
- **W-002를 Phase 50 계약 확정 전에.** 양쪽을 두 번 고친다.
