# Phase 26 — 마감일을 화면에서 넣을 수 있게

착수 근거: `/loop-eng` SCOPE(5장). 감사 각도가 마르던 차에 **제품 쪽에서 실제 공백**을 찾았다.

## 발굴 — 데이터를 쓰는 기능은 있는데 넣을 방법이 없다

할 일 위젯에는 마감일에 기대는 기능이 이미 셋이나 있다.

| 기능 | 위치 |
|---|---|
| "오늘 마감" 필터 버튼 | `TodoWidget.tsx:343` |
| "오늘 마감인 할 일이 없어요" 빈 상태 | `TodoWidget.tsx:432` |
| 기한 지난 할 일을 빨갛게 | `TodoWidget.tsx:512` |

그런데 **사용자가 마감일을 지정할 방법이 화면에 없다.** `handleAdd`는 제목만 넘기고,
행에서 고칠 수 있는 것도 제목·완료·반복뿐이다. 날짜 입력(`type="date"`)은 캘린더 위젯과
데이터베이스 뷰에만 있고 할 일에는 없다.

결과: **"오늘 마감" 버튼을 눌러도 영원히 빈 목록이다.** Phase 23에서 오리가 마감일을 넣을 수
있게 됐지만, 그건 "오리에게 말해야만 되는 기능"이라는 뜻이기도 하다.

이건 새 기능 추가가 아니라 **이미 만든 기능을 실제로 쓸 수 있게 하는 일**이다.

## 중복 방지 확인 (코드로)

| 후보 | 확인 결과 | 판정 |
|---|---|---|
| 할 일 마감일 입력 UI | `TodoWidget`에 `type="date"` 0건, `handleAdd`는 제목만 | **없음** → T1 |
| 마감일 저장 계약 | `createTodo`/`updateTodo`가 `dueDate`를 이미 받는다 | 이미 있음 — 재구현 안 함 |
| 날짜 → 저장 형식 변환 | api `coerceTodoDueDate`(Phase 23, 8 tests) | 이미 있음 — **재사용** |
| 마감일 표시 | 기한 초과 빨간색만 있고 날짜 자체는 안 보임 | 배지 추가 |

## 설계 결정 (ponytail 7단계)

- **저장 형식 변환을 다시 짜지 않는다.** Phase 23에서 `T00:00:00.000Z`(UTC 자정) 규약을 정하고
  테스트로 잠갔다. 화면에서 또 만들면 **규약이 두 곳에서 갈라진다** — 그게 이 저장소가 여러 번
  겪은 실패 방식이다. `@ldd/api`에서 `coerceTodoDueDate`를 내보내 그대로 쓴다.
  (순수함수라 core가 더 어울리지만, 이미 api에서 테스트까지 있는 걸 옮기는 건 이번 목적 밖이라
  내보내기 한 줄로 끝낸다.)
- **추가 폼이 아니라 행에 붙인다.** 마감일은 보통 만든 다음에 정하고, 잘못 잡으면 고쳐야 한다.
  추가 폼에만 두면 나중에 못 바꾼다. 행에 두면 신규·기존 둘 다 된다.
  또 반복 설정이 이미 행에 있으므로 **같은 자리·같은 규칙**으로 두어야 행에 패턴이 둘로 갈리지 않는다.
- **컨트롤 폭을 아이콘 크기로 고정한다.** `<input type="date">`는 기본 폭이 넓어서, 안 보이게
  둬도 모든 행의 제목 공간을 잠식한다 — 반복 select에서 이미 겪은 문제다(Phase 21에서 수정).
  같은 방식(고정 크기 래퍼 + 투명 입력 겹치기)으로 처음부터 막는다.
- **값은 배지로 보여준다.** 설정된 날짜가 안 보이면 왜 "오늘 마감"에 걸리는지 알 수 없다.

## Task

### T1 마감일 설정 UI (web)
- **수용 기준**:
  - 행에서 마감일을 지정·변경·해제할 수 있다.
  - 설정된 마감일이 행에 보인다(오늘/내일은 말로, 그 외는 날짜).
  - 저장 형식은 `coerceTodoDueDate`가 만든 값 그대로 — **"오늘 마감" 필터에 실제로 걸린다.**
  - 컨트롤 폭이 아이콘 크기를 넘지 않는다(제목 공간 잠식 금지).
  - 실패 시 조용히 넘기지 않고 알린다.
- **의존 계약**: `@ldd/api`에 `coerceTodoDueDate` 내보내기 추가. 스키마·마이그레이션 변경 없음.

### T2 표시 로직 테스트 (web lib)
- **수용 기준**: 날짜 → 표시 문구 변환이 순수함수로 분리돼 테스트된다(오늘·내일·어제·그 외,
  깨진 값). 저장 형식(UTC 자정)을 로컬 변환에 태워 **하루 밀리는 일이 없어야 한다.**
