## Task

### T1 — 목록에서 바로 마감일 설정 (핵심)
- 각 할 일 줄의 마감 라벨(없으면 "+ 마감" 버튼) 클릭 → 인라인 date 입력 → 즉시 저장.
- 저장 규약은 기존 한 벌: `coerceTodoDueDate`(UTC 자정) + `handleDueDateChange` 재사용.
- **확인 먼저**: 수정 모드의 date 입력(TodoWidget 585행 부근)과 중복되지 않게 — 같은
  핸들러를 공유하고 입구만 늘린다.
- AC: 마감일 설정 직후 "오늘 마감" 필터·라벨(dueDateLabel)과 즉시 일치. 잘못된 날짜는
  기존 오류 문구 그대로.

### T2 — 마감 상태 시각화·마감일순 보기
- 지난 마감(overdue) 강조는 **이미 있다**(TodoWidget 538행 부근) — 재구현 금지, 오늘
  마감 강조만 추가 검토.
- "마감일순 보기" 토글: 사용자 지정 순서(todoOrder)와 충돌하지 않게 **보기 전용 정렬**
  (저장 순서는 그대로).
- AC: 토글 시 마감일 없는 항목은 뒤로. 끄면 원래 순서 복귀.

### T3 — 오리가 오늘 마감을 먼저 말하기
- **확인 먼저**: `duck-initiative`의 dueToday 신호가 대시보드 인사/말풍선에 이미 연결돼
  있는지. 연결돼 있으면 이 Task는 폐기(중복 금지).
- 미연결이면: 대시보드 진입 시 오늘 마감 n건을 오리 한마디로(기존 initiative 파이프 재사용).

### T4 — 반복 할 일 마감 이월 검증
- **확인 먼저**: `rolloverDueDate`(core)가 완료 시 실제로 호출되는지. 호출되면 폐기.
- 미호출이면 완료 경로에 배선 + 테스트.
