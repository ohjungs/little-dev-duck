### 추가 완료 (iteration 3)
- **위젯 접기 버튼 겹침 수정**: 펼침 상태 접기(˅)가 위젯 자체 헤더 컨트롤과 상시 겹치던 것 →

- **애니메이션 오리 로고**(DuckLogo, SVG+CSS): 로그인의 이모지+png 중복 로고 제거, 마운트 시 "꽥"
  인트로 + hover 반응. 로그인·AppNav 좌상단·접힌 사이드바 통일(MGM 사자 인트로의 오리판 1차).
- **대시보드 오리를 픽셀아트 스프라이트로 교체**: SVG 병아리가 "못생겼다"는 피드백 → 기존 픽셀 오리
  시트(ducky_2, 우측면 뷰, Brysia 레퍼런스와 동일 계열)를 CSS 스프라이트 애니로. **Playwright로 시트
  레이아웃 실측**(row0=idle 2프레임, row1=걷기 6프레임)해 빈 프레임 밟던 버그 없이 매핑. 기분별
  애니(idle/뒤뚱걸음/기울임)+클릭 폴짝+레벨업 점프.
- **Modern Interiors 에셋 추출·커밋**: 오피스용 캐릭터/타일셋을 public/sprites/modern-interiors에 준비.
- **Playwright 시각 검증 워크플로 구축**: chromium 설치. 스프라이트/컴포넌트를 오프스크린 렌더→스크린샷→
  확인. 남은 오피스 비주얼 작업에 활용.
