# 메신저 734항목 — 전수 Phase 배정표

> **이 표는 코드로 생성했다.** 734행을 손으로 옮기면 반드시 틀린다 — HD-003(결정적 작업은 코드로).
> 생성기가 **누락·중복·원본에 없는 ID를 0으로 검증**한 결과만 싣는다.
>
> 원본(무수정): [messenger-features-original.md](messenger-features-original.md)
> 중복 대조·판정 조정: [messenger-features.md](messenger-features.md)

## 검증 결과

```
전체 734 / 배정 734 / 미배정 0 / 중복 배정 0 / 원본에 없는 ID 0
```

**검사가 실제로 결함을 잡아냈다** — 이게 코드로 만든 이유다:

- **K-001(이미지 업로드, MUST)이 배정에서 빠져 있었다.** Group 0에 H-002(이미지 메시지)를
  넣었으면서 **업로드를 안 넣었다** — 그러면 이미지 메시지를 만들 수 없다.
- **F-002(Enter 전송, MUST)가 Phase 54로 밀려 있었다.** 그거 없이는 Phase 50에서
  **메시지를 보낼 수가 없다.** P50으로 되돌렸다.
- 중복 배정 2건(W-005·W-007)을 잡았다. W-005(커맨드 팔레트)는 L-024와 같은 것이고
  `CommandPalette.tsx`로 **이미 있다** — 배정이 아니라 판정 오류였다.
