# 404 화면 — 2026-07-26 (Phase 38)

**아직 스크린샷이 없습니다.** 404 화면은 **로그인해야만** 보입니다 —
비로그인 상태로 없는 주소를 열면 미들웨어가 `/welcome`으로 303을 보냅니다(실측).

세션 파일(`PENDING.md` 2번)이 생기면 `not-found-csp.spec.ts`가 자동으로 돌면서
`not-found__default__desktop.png`를 여기에 남깁니다.

## 이 폴더가 검사하는 것

`lessons-learned.md`의 **재발견 1회짜리** 교훈 — "nonce 기반 CSP는 정적 프리렌더링 페이지에서
무효". 빌드 때 구운 스크립트가 매 요청의 nonce와 불일치해 `strict-dynamic` 아래서 전부 막힙니다.
처음 겪었을 때는 `/login`이 정적이라 **로그인이 완전 불능**이었고 실사용자가 발견해 줬습니다.

**이번에 `/_not-found`가 같은 상태였습니다.** `force-dynamic`으로 고쳤고 빌드 출력이
`○`(정적) → `ƒ`(동적)으로 바뀌는 것을 확인했습니다.

## 실행으로 확인한 것 / 못 한 것

| 항목 | 상태 |
|---|---|
| 빌드 출력이 `ƒ`로 바뀜 | **확인함**(`next build` 출력) |
| 회귀 방지 가드가 동작 | **확인함**(e2e globalSetup에서 실행, 현재 위험 페이지 0건) |
| 실제 브라우저 콘솔에 CSP 위반 없음 | **못 함** — 로그인 필요 |

교훈 본문이 "curl 헤더만으로는 못 잡는다, 실제 브라우저로 봐야 한다"고 못박은 부분이
마지막 줄입니다. 그래서 스펙을 써 두고 세션 파일을 기다립니다.
