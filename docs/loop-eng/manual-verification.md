# 사용자 실기검증 대기 목록 (loop-eng defer-and-continue)

> /loop-eng 8-1 규칙: 자율 루프가 코드로 완결할 수 없고 **사용자의 실기(수동) 검증·승인·인프라**가
> 있어야만 확정되는 항목을 여기에 보류 기록한다. 루프는 멈추지 않고 다음 자율 Task로 넘어간다.
> 형식: 날짜 · Task · 무엇을 · 왜 사용자 필요 · 재현 절차 · 현재 상태.

## 현황 요약 (2026-07-25)

자율 코드-완결 스코프는 **소진**됨(Phase 1~17 전 슬라이스 코드 완료, web lib 순수함수 추출 완료).
아래 항목은 전부 사용자 인프라/기기/육안이 열려야 진행 가능하다. 하나라도 열리면 해당 항목으로 즉시 재개.

## 1. OAuth 어댑터 기기 실기검증

- **Task**: Phase 10 — Google Calendar / GitHub 이슈 / Gmail 어댑터.
- **무엇을**: 로그인→provider_token 캡처→승인 카드→실제 외부 API 반영→감사 로그까지 end-to-end.
- **왜 사용자 필요**: 실제 OAuth 로그인 플로우·외부 계정 권한이 필요. 무인 세션은 브라우저 로그인 불가.
- **재현 절차**: 배포된 웹에서 Google/GitHub 로그인 → 설정에서 어댑터 연동 → 오리에게 "내일 회의 잡아줘"
  등 액션 요청 → 승인 카드 확인 → 실제 캘린더/이슈/메일에 반영됐는지 대조.
- **현재 상태**: Google Calendar는 2026-07-23 사용자 검증 통과(종결). GitHub 이슈·Gmail 어댑터는 코드 완료·미검증.

## 2. Sentry 계정 (Phase 13 T5 — PII 스크러빙)

- **무엇을**: Sentry 프로젝트 생성 + DSN 발급 → 에러 리포팅 + PII 스크러빙 구성.
- **왜 사용자 필요**: 외부 계정 생성·DSN은 사용자 몫. 무료 티어 원칙상 계정 소유자 결정 필요.
- **현재 상태**: 미착수(이월). DSN이 열리면 서버 env 주입 + 스크러빙 룰 구현 가능.

## 3. i18n 착수 승인 (Phase 13 T6)

- **무엇을**: 다국어(최소 한/영) 문자열 추출 + 라우팅.
- **왜 사용자 필요**: 대규모 변경(전 화면 문자열 외부화) — 스코프·우선순위 사용자 승인 필요.
- **현재 상태**: 로드맵 후반 이월. 승인 시 /spec-loop로 스펙 먼저 잠그고 착수 권장.

## 4. Tauri sidecar / hooks · React Native 기기 (Phase 16/17 이월분)

- **무엇을**: Claude Code hooks → 오피스 이벤트, Tauri sidecar WebSocket 중계, RN Expo 스캐폴드·기기 검증.
- **왜 사용자 필요**: 데스크톱 빌드·기기 시뮬레이터·실 hooks 소스가 필요. 무인 세션 부적합.
- **현재 상태**: 웹 슬라이스는 코드 완료. 데스크톱/모바일 통합은 기기 참여 세션 이월.

## 5. 픽셀 오피스 시각 폴리시 육안 검증

  결정적 테스트로는 "보기 어색함"을 못 잡는다.
