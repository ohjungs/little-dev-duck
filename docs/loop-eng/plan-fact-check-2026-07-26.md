# 2차 피드백 계획서의 근거 대조 (2026-07-26 `/loop-eng`)

`docs/feedback-2026-07-26-2.md`의 "조사 결과 — 원인이 확정된 것" 절이 내세운 **구체적 근거
9건을 코드로 전수 대조**했다. 그 문서 위에 Phase 41~49가 세워지므로, 틀린 전제가 있으면
아홉 개가 함께 틀어진다.

**왜 다른 세션 산출물을 검증했나**: 이 사이클은 [동시 작업 회피](../../CLAUDE.md) 때문에 개발을
시작할 수 없었다(다른 세션이 같은 작업 디렉터리에서 계획서를 쓰고 있었다 — 9-4 규칙).
개발 대신 **충돌이 원리적으로 불가능한 읽기 전용 작업**을 골랐다.

## 정정 1건 — 도구모음 재고 (2-1·2-2·2-3에 영향)

문서는 버튼 **9개**로 적고 `즐겨찾기·표지·버전·인쇄·발표·텍스트복사·가져오기·데이터베이스로
전환·웹에 공개`를 나열했다. 실제로 `PageEditor.tsx` 488~629줄(그 `div`의 실제 범위,
태그 깊이로 계산)에 있는 것은:

| # | 라벨 | 종류 |
|---|---|---|
| 1 | 즐겨찾기 / 즐겨찾기됨 | `<Button>` |
| 2 | 버전 저장 | `<Button>` |
| 3 | 버전 기록 | `<Button>` |
| 4 | **복제** | `<Button>` |
| 5 | **Markdown 내보내기** | `<Button>` |
| 6 | **템플릿으로 저장** | `<Button>` |
| 7 | 인쇄 · PDF | `<Button>` |
| 8 | 발표 | `<Button>` |
| 9 | 텍스트 복사 | `<Button>` |
| 10 | 가져오기 | **`<label>` + 숨은 file input** (버튼이 아니다) |
| 11 | 데이터베이스로 전환 | `<Button>` |
| 12·13 | 공개 링크 복사 · 공개 취소 (공개 상태) | `<Button>` ×2 |
| 14 | 웹에 공개 (비공개 상태) | `<Button>` |

- 선언된 상호작용 요소 **14개**(`<Button>` 13 + `<label>` 1).
- 공개 상태 3개는 **서로 배타적**이라(공개면 12·13, 비공개면 14) **동시에 렌더되는 것은 13개.**
- **"표지"는 이 행에 없다.** 커버 입력을 여는 버튼은 **658·679줄**로, 커버 영역에 마우스를
  올릴 때 나타나는 별도 버튼이다(도구모음 밖).
- 문서가 누락한 것: **복제 · Markdown 내보내기 · 템플릿으로 저장**, 그리고 **버전이 하나가
  아니라 둘**(저장·기록).

### 이 정정이 계획에 주는 영향

1. **넘침 결론은 약화되지 않고 강화된다.** 768px 고정 폭에 줄바꿈 없이 들어가는 것이
   9개가 아니라 **13개**다. 사용자가 "즐겨찾기 ~ 웹에공개까지 깨진다"고 말한 범위와도 맞는다.
2. **"2-2·2-3으로 9개 → 4개"라는 산술은 다시 세야 한다.** 내보내기 통합(2-2)이 흡수하는 것은
   `Markdown 내보내기`·`텍스트 복사`·`인쇄 · PDF`·`템플릿으로 저장`·`가져오기` **5개**이고,
   DB 전환 이관(2-3)이 1개를 빼면 13 − 5 − 1 + 1(모달 버튼) = **8개**가 남는다. 4개가 아니다.
3. **8개도 768px에서 여전히 위험하다** → `flex-wrap` 즉시 조치(문서의 Phase 42 판단)는
   근본 해결과 **별개로 계속 필요하다.** 통합만으로는 안 끝난다.

## 확인했지만 문제가 아니었던 것 (오탐 방지 기록)

- **도구모음에 `aria-label`이 하나도 없다** — 처음엔 접근성 결함으로 의심했다. 확인해 보니
  **모든 버튼에 보이는 한국어 텍스트가 있어** 접근성 이름이 텍스트로 제공된다.
  `텍스트 복사`는 JSX 표현식(`{textCopied ? … : …}`)이라 내 첫 정규식이 놓쳤을 뿐이다.
  `unnamedControl.test.ts` 가드에도 빈틈이 없다. **없는 문제를 만들지 않았다.**

## 검증 방법

전부 코드로 판정했다(HD-003) — `sed`로 해당 줄 직접 확인 · 태그 깊이 계산으로 `div` 실제 범위
산출 · `<Button>`/`<label>` 개수 집계 · `grep -c`로 `Notification`·차트 참조 0건 확인.
문서 수정은 하지 않았다 — **다른 세션이 소유한 파일이라 손대지 않는다.**
